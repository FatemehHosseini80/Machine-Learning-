
# Linear Regression Implementation & Analysis

This repository contains a Python project demonstrating the fundamental concepts of Linear Regression. It includes from-scratch implementations of optimization algorithms for single-variable linear regression, as well as an exploratory data analysis (EDA) for a multiple-variable linear regression problem (Medical Insurance Cost Prediction).

## 🚀 Project Overview

The project is divided into two main parts:
1. **Single Variable Linear Regression**: 
   - Uses `dataset1.csv`.
   - Implements the cost function (Mean Squared Error).
   - Solves for weights using the **Closed-Form solution (Normal Equation)**.
   - Implements **Stochastic Gradient Descent (SGD)**.
   - Implements **Batch Gradient Descent (BGD)**.
   - Visualizes and compares the prediction lines of all three methods against the raw data.
2. **Multiple Variable Linear Regression**:
   - Uses `train.csv` and `test.csv` (Medical Insurance data).
   - Performs Exploratory Data Analysis (EDA) on features (`age`, `gender`, `bmi`, `children`, `smoker`, `region`) and the target variable (`charges`).
   - Visualizes numerical feature distributions and their relationships with the target variable using Matplotlib and Seaborn.

## 📂 Files Included

- `Linear_Regression.ipynb`: The core Jupyter Notebook containing the code, formulas, and visualizations.
- `dataset1.csv`: Dataset used for single-variable linear regression.
- `train.csv` & `test.csv`: Medical insurance datasets used for multiple-variable linear regression EDA.

## 📊 Algorithms Implemented

### Closed-Form Solution (Normal Equation)
Calculates the exact parameters without iteration using linear algebra:
`θ = (XᵀX)⁻¹ Xᵀ y`

### Stochastic Gradient Descent (SGD)
Updates the parameters iteratively for each individual training sample, which can lead to faster convergence on large datasets but with higher variance in the parameter updates.

### Batch Gradient Descent
Updates the parameters after computing the gradient over the entire dataset in a single step, ensuring steady and stable convergence.

## 📈 Visualizations
- **Regression Comparison**: A combined scatter plot showing the raw data overlaid with the regression lines generated by Closed-Form, SGD, and Batch Gradient Descent methods.
- **EDA Distributions**: Histograms with KDE (Kernel Density Estimation) for features like `age`, `bmi`, `children`, and `charges`.
- **Feature Relationships**: Scatter plots checking the linear relationships between numerical features and the target `charges`.
